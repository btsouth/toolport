# AUR repackage retired

Toolport 2.0 Linux system packages use the GTK shell. The Tauri `.deb` renderer
and AUR publication workflow are retired. Arch users should use the
[native pacman package](../../../docs/arch-pacman-repo.md), built from
[`packaging/linux/native/PKGBUILD`](../native/PKGBUILD).

The Tauri AppImage remains available for distributions with older libadwaita.
